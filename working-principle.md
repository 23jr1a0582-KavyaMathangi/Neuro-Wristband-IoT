# Working Principle

1. Place the wristband correctly on the wrist, following the sensor manufacturer's placement guidance.
2. The heart-rate and SpO₂ sensors collect physiological signals.
3. The ESP32 reads the sensor outputs and processes the measurements.
4. The program compares the readings against thresholds selected and validated for the prototype.
5. The corresponding green, yellow, or red LED is activated.

**Important:** This describes the intended prototype workflow. Actual sensor models, thresholds, calibration, and test results should be documented accurately. The prototype is not a substitute for medical assessment.
